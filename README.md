
# SmartNote

A modern note-taking application built with **React** and **Vite**,
designed to help you capture ideas, organize notes, and keep important
information close at hand.

## Live Demo

**Try SmartNote here:**\
https://smart-note-k26e-ivory.vercel.app/

## Overview

SmartNote is a personal note-taking workspace with tools for creating
and organizing notes. Its interface brings everyday note management
features together in one place, with a focus on a clear and practical
user experience.

## Features

-   **Notes management** --- create and manage your notes.
-   **Favorites** --- keep important notes easy to find.
-   **Categories** --- organize notes by topic.
-   **Trash** --- move unwanted notes out of the main workspace.
-   **Reminders and calendar** --- keep track of note-related dates.
-   **Goals** --- maintain a view of personal goals.
-   **Backup tools** --- access the application's backup features.
-   **Markdown support** --- write formatted content in the note editor.

> Feature availability and behavior may depend on the current deployed
> version.

## Tech Stack

-   **React** --- user interface
-   **Vite** --- development server and production build
-   **JavaScript**
-   **CSS**
-   **React Markdown** and **remark-gfm** --- Markdown rendering and
    GitHub Flavored Markdown support

## Getting Started

To run SmartNote locally:

### 1. Clone the repository

``` bash
git clone https://github.com/p-delfani/SmartNote.git
```

### 2. Open the project directory

``` bash
cd SmartNote/my-app
```

If you cloned the repository into a different folder structure, navigate
to the directory that contains `package.json`.

### 3. Install dependencies

``` bash
npm install
```

### 4. Start the development server

``` bash
npm run dev
```

Open the local URL shown in your terminal.

## Production Build

To create an optimized production build:

``` bash
npm run build
```

To preview the production build locally:

``` bash
npm run dev
```
